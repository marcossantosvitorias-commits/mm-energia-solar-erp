# Deploy na Hostinger

Use estas configurações no Web App da Hostinger:

- Diretório raiz: `MM_ERP_GitHub_Pronto/apps/web`
- Comando de construção: `npm run build`
- Diretório de saída: `dist`
- Arquivo de entrada: deixe vazio
- Versão do Node: 22

O frontend agora gera a pasta `dist` dentro de `apps/web`, exatamente onde a Hostinger espera encontrá-la.
