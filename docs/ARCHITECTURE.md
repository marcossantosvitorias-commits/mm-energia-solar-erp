# MM ERP AI - Architecture

## Vision
Construir um ERP especializado para empresas de energia solar, modular, escalável e preparado para IA.

## Camadas
- Frontend: React + Vite
- Backend: PocketBase (fase inicial), evoluindo para PostgreSQL/API
- Autenticação e permissões por perfil
- Componentes reutilizáveis

## Módulos
1. Dashboard
2. CRM
3. Clientes
4. Comercial
5. Engenharia
6. Financeiro
7. Estoque
8. Obras
9. Licitações
10. IA
11. Configurações

## Princípios
- Código limpo
- Componentização
- Responsividade
- Versionamento por sprint
- Documentação contínua
